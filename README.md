# Tacoma Launcher

Pantalla de inicio para radios Android de Toyota Tacoma 2005-2013: la camioneta con los datos
del motor (escáner OBD2), mapa, música con letra, mantenimiento y viajes.

## Instalar en un radio nuevo

1. En el radio, abre el navegador y entra a:

   **https://github.com/hernanheri/tacoma-launcher-releases/releases/latest/download/TacomaLauncher.apk**

2. Abre el archivo descargado y toca **Instalar**. Si el radio dice que está bloqueado, toca
   **Ajustes**, activa **Permitir de esta fuente** y regresa.
3. Presiona **Inicio** y elige **Tacoma** → **Siempre**.

## Actualizaciones

La app busca versiones nuevas sola. Cuando hay una, pregunta si quieres actualizar: toca
**Actualizar ahora** y luego **Instalar**. Tus ajustes se conservan. También puedes buscar a mano en
**Ajustes → Actualizaciones**.

¿Dudas? Contacta a tu instalador.
